# Assignment 2 – Q1

Original field-service technology audit and reproducible case (e) simulation.

## Contents
- [Q1 report](Q1_Report.md)
- `q1.py`: Monte Carlo simulation
- `data/simulation_results.csv`: averaged results
- `requirements.txt`: Python dependencies

## Run
```bash
pip install -r requirements.txt
python q1.py
```

The simulation uses 5,000 trials, a fixed seed, 60 updates in a 360-minute shift, a 12-item FIFO queue, and per-minute independent link availability. The CSV is regenerated by the script.
