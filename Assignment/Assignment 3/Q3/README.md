# Q3 – Cellular Networks versus Ad Hoc Wireless Networks

Computes shortest multi-hop routes in a sample mesh and compares hop delay with a simplified cellular access/core path. The report covers infrastructure, mobility, topology, scalability and failure behaviour.

Run `python implementation.py` to regenerate `output.csv`. The 12 ms per mesh hop and 32 ms cellular comparison are explicit illustrative assumptions, not measured carrier-network performance.
