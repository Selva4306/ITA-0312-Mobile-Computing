# Q7 – Emergency Network Design Challenge

Calculates the hybrid disaster-network design budget: AODV repairs movement inside the mesh; Mobile IP is used only when a gateway/foreign-agent changes. Outputs gateway handoff frequency, registration signalling, interruption and tunnel overhead.

Run `python implementation.py` to regenerate `output.csv`. The assignment report includes design pseudocode, failure handling, validation assumptions and DSDV/AODV comparison. This is an analytical model, not a live mesh emulator.
