# Q5 – Proactive Routing Protocols (DSDV)

Calculates periodic full-table DSDV control traffic from node count, 5 s update interval, 24-byte header and 12-byte route entries. The separate dataset contains the assignment report's simulation observations.

Run `python implementation.py` to regenerate `output.csv`. The formula is a control-load model; observations in `dataset.csv` are transcribed from the submitted report and are not claimed as a new emulator run.
